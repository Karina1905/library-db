# Система управління бібліотекою

Лабораторна робота з сучасних технології баз даних. Проєкт на PostgreSQL і Python.

В базі 20 таблиць: читачі, книги, видачі, штрафи, бронювання, додаткові послуги (кімнати, сервіси) та інші. Є Soft delete, поля з датою і автором останньої зміни та таблиця audit_log для історії змін.

У папці db лежать SQL-скрипти: таблиці, індекси, функції, представлення, процедури, тригери і тестові дані. У папці app лежить Python-код з патернами Repository і Unit of Work. Усі запити йдуть через процедури та представлення. У docs/schema.dbml лежить схема для dbdiagram.io.
